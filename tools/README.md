# أدوات البناء

الـ repo يحتوي الناتج المبني فقط. بعد أي تعديل على ملف `app*` أو `data-*` أو `store*` أو `index.html`:

    node tools/build.mjs          # يعيد التهشير ويحدّث index.html و sw.js
    node tools/build.mjs --bump   # نفس الشيء مع رفع رقم الإصدار (الثالث)

لا تعدّل `sw.js` يدويًا (قائمة FILES واسم الكاش يُولَّدان).

## إكمال القراءات المبتورة

    node tools/readings-complete.mjs          # تقرير فقط
    node tools/readings-complete.mjs --write  # يعدّل src/app5.js ثم node tools/build.mjs

نصوص القطمارس (الإنجيل والبولس والكاثوليكون والإبركسيس، اليومية والآحاد) المبتورة أو التي فيها علامة حذف «...» تُحاذى كلمةً كلمة مع آيات مرجعها في الكتاب المقدس داخل البرنامج؛
فالآية الموجودة تبقى بتشكيلها المطبوع، والناقصة تُؤخذ بتشكيلها من قراءة أخرى فيها الآية نفسها إن وُجدت، وإلا من الكتاب المقدس (فان دايك) بلا تشكيل.
ويقيس `tools/qa/readings-coverage.mjs` اكتمال كل القراءات بعد ذلك.
